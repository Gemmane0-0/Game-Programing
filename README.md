Description: Our game was a racing game. You the player are able to race around the track, you need to make a loop around the course in order to win. In doing so, there will be obstacles in the track trying to get in the players way, if hit, the player will lose 1 hp, they have a total of 5hp. If the timer runs out you will lose and have to restart. We added a boost mechanic so the player can get around the map faster.
